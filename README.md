## 📖 About This Repository
This is not just a collection of code snippets. It is a **Knowledge Repository** designed to document my journey from fundamental Python structures to complex algorithms. 

**The Core Philosophy:**
1. **Implement from Scratch:** No `import queue`. I build the Queue class to understand *how* it works.
2. **Analyze Everything:** Every algorithm includes Big O Time & Space complexity analysis.
3. **Test Driven:** Concepts are verified with Unit Tests to ensure reliability.
4. **Integration Projects:** "Stitch Weeks" where I combine multiple structures to build mini-systems (e.g., Music Players, Browser History).

## 🛠️ How to Run

I use pytest to verify that my custom data structures behave correctly.

#### 1. Clone the repo
```bash
git clone https://github.com/KHUSHWANTsRathore11/DSA.git
```
#### 2. Run the tests
```bash
# Run all tests
pytest tests/

# Run specific structure test
pytest tests/test_linked_list.py
```
